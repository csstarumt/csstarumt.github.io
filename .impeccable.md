# Design Context

English information site for TARUMT Computer Science Society. Students discover the society, events, membership and albums. User approved the generated bright technology concept and allows a multi-page layout.

Brand: bright, technological, welcoming. Cool white, navy, cobalt blue, subtle engineering grid, real society photos and existing logo. Space Grotesk headings and DM Sans body. Generous whitespace and restrained animation. Avoid neon/dark treatment, invented statistics and generated people. Mobile layouts rearrange rather than shrink.

Maintain content in GitHub Markdown. Astro static site on GitHub Pages. Review changes through a feature-branch PR before merging to main.

## Revised direction
User rejected the first implementation as too ordinary. Confirmed Interactive Tech Lab: bright blue-white with a read-only Live CSS Playground (Shape, Orbit, Type, Sculpture), dynamic typography, meaningful component interactions, animated filters, photo deck and command search. Particle and standalone 3D lab concepts were retired. Maintain real content and reduced-motion/static fallback.
